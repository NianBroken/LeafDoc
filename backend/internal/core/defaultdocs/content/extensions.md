# 数学公式、Mermaid 与排错

## 块级数学

```markdown
$$
a^2+b^2=c^2
$$
```

$$
a^2+b^2=c^2
$$

当前预览关闭单美元符号的行内数学解析，`$HOME` 保留为普通文本。公式应使用独立的双美元符号围栏，不能假定所有 Markdown 平台支持相同扩展。

## Mermaid 图表

```mermaid
flowchart LR
    A[输入正文] --> B[检查预览]
    B --> C[保存页面]
```

使用标记为 `mermaid` 的代码围栏，图表组件将其渲染为图形。语法错误会阻止该图形正确显示，应检查箭头、节点和围栏。

## 排错顺序

1. 检查代码围栏是否闭合。
2. 检查列表缩进和表格分隔行。
3. 检查页面、图片和附件目标。
4. 保存并重新打开，区分尚未保存和渲染问题。

原始 HTML 会经过清理，脚本、事件属性及不允许的样式不作为功能使用。练习将公式与图表分别放在独立块中，确认正文后面的段落仍正常显示。

## 数学写法的边界

数学块使用 LaTeX 风格表达式，分隔符单独成行便于维护。变量、上下标和分数应先用最小表达式验证，不一次粘贴整篇复杂公式。单美元符号被保留是为了避免命令环境变量被误认，正文里的金额和 shell 参数不应突然变成数学。

## 图表内容与源码

Mermaid 图表由代码块文本生成，修改节点或箭头后重新检查预览。节点文字尽量简短，用正文解释完整步骤。图表强调关系，不替代实际命令。图中画了自动恢复，不等于服务器已经配置自动恢复，真实行为仍需部署和验证。

## 分段定位错误

正文格式出错时，先查看问题之前最近的围栏。一个未闭合围栏会影响后面全部段落。图表错误只保留两个节点和一条箭头再试，公式错误先移除复杂命令。确认最小版本可显示后逐项加回，这样能定位具体写法而不是反复刷新。

## HTML 与跨平台差异

原始 HTML 会经过允许列表清理，不保证复制任意网页片段保持原样。其他 Markdown 工具里的特殊提示块、脚本图表和样式不自动成为本项目支持能力。迁移内容时优先改成标题、列表、表格和代码等明确结构。

## 最终练习

建立一段块级公式和一幅流程图，下方各写一句结果说明。保存后重新打开，公式应显示数学排版，图表应显示节点连接，后续正文仍是普通段落。再检查所有导航目标实际存在，确认不是仅在编辑时看到了未保存的内容。
