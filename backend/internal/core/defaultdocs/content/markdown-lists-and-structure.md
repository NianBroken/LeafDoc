# 列表、引用与内容组织

## 用列表表达动作

无序列表用于并列事项，有序列表用于必须按顺序执行的动作。每项只承担一个动作或一个判断。

```markdown
1. 打开系统入口。
2. 输入账号和密码。
3. 登录后打开文档树。

- 阅读记录
- 下载附件
- 检查链接
```

## 子列表与任务记录

子列表需要缩进，使它归属于上一项。修改缩进后查看预览，确认子项没有变成独立段落。

```markdown
- 检查系统
  - 打开首页
  - 查看搜索

- [x] 已核对访问入口
- [ ] 待补充备份位置
```

任务框用于文章中的状态表达。不能据此认定系统执行了对应工作，也不能把显示勾选等同于后台任务成功。

## 引用与分隔

```markdown
> 操作前应保留一份可恢复的数据副本。

---
```

引用适合突出一条独立说明，不能代替真实来源。分隔线用于切换大段内容，常规层次优先使用标题。避免每行都加分隔线，也不要把多种列表嵌套到读者无法判断先后关系的程度。

## 把清单写成可判断的结果

“检查部署”没有说明检查什么。写成“打开 HTTPS 首页，登录后读取一篇页面，确认内容完整”，读者才能判断工作是否完成。
