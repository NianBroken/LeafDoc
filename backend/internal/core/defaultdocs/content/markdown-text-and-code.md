# 标题、文本格式与代码

## 标题与强调

标题在井号后留一个空格。一级标题标示文章主题，二级标题划分任务，三级标题解释具体步骤。不要依靠大量加粗模拟层次。

```markdown
# 运维手册
## 查看服务
### 检查入口
普通文字、**重点文字**、*强调文字*和 ~~不再采用的方案~~。
```

## 行内代码与代码块

文件名、命令和字段名放进行内代码，例如 `other/compose.yaml`。多行命令使用围栏代码块。语言名称提供给高亮器，不能代替运行环境说明。代码块只展示文本，不会自动执行其中的命令。

```bash
printf '%s\n' '检查服务状态'
```

复制代码前确认自己处于正确目录，并理解命令是否会删除数据。文档中的演示命令不会替你创建业务环境。

## 空行与特殊字符

同一段中的换行不等于开启新段落。不同任务之间插入空行，避免说明与代码连成一个难以阅读的段落。需要展示井号、星号等标记本身时，用反斜杠转义或包进行内代码。

写完后检查预览中的代码缩进、换行和强调范围。如果后续所有文字都被显示为代码，检查围栏是否闭合，起止反引号的数量是否匹配。
