# 链接与资源导入练习包

本目录用于验证 ZIP 导入，不用于安装 LeafDoc。保留 Guides、Reference 与 shared 的相对位置，打包整个目录后在导入界面创建计划，核对路径和冲突，再执行。

## 检查内容

- Guides/Setup.md 包含普通相对链接、根路径资源、Wiki 图片以及不应被改写的代码示例。
- Reference/API.md 用于检查保留名称处理。
- Guides/images/logo.png 与 shared/manual.pdf 必须和正文一起导入。

## 结果检查

打开导入页面，检查目标文档和附件可访问，代码围栏内的原始链接仍按源码展示。不要把本练习 README 当作主项目操作手册。
