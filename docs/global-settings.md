# 全局设置与运行验证

实例偏好保存在数据目录的 `preferences.json`，所有访问者读取同一份配置。缺省语言为简体中文，日期采用 `YYYY-MM-DD`，时间采用 24 小时制，自动保存开启。管理员通过 `/settings/preferences` 修改偏好。日期与时间必须选择明确格式，不接受 `locale`。

公开访问缺省开启，仅授予匿名只读能力。管理员能够修改公开访问、品牌及目录默认状态。目录有自动显示、始终显示和始终不显示三种默认模式。前台目录按钮仅改变当前文档访问的显示状态，不写入服务器或长期浏览器存储。

`/api/config` 提供公开配置、实例标识与版本。客户端通过 `/api/settings/events` 接收版本通知，并在重连及页面恢复可见时重新读取配置。服务器持久化成功后才发布通知。实例标识用于区分重启前后的版本序列，客户端忽略同一实例的旧响应。

全局写接口要求管理员会话及请求防护令牌。账户头像和本人密码独立保存。界面之外的主题、工具栏和布局保持浏览器独立。

新数据目录首次创建管理员 `NianBroken`，初始密码为 `Nian123456`。首次登录后仅允许识别会话、退出及修改本人密码。服务器拒绝受限账户访问其他业务接口。修改密码必须验证原密码，且新密码不能与原密码一致。密码与强制改密状态同时更新，后续登录使用新密码。已有管理员的数据目录不会重置账户。

后端错误、邮件、日期、相对时间和单位使用全局语言。前端错误翻译为权威来源，执行前端构建时由 `scripts/sync-error-catalogs.mjs` 同步服务端错误目录。支持的五种语言保留相同翻译键。

## 自动验收

使用 Python 3 和已经编译的 LeafWiki 可执行文件运行：

```powershell
python -X utf8 scripts/verify-global-settings.py --binary <可执行文件路径> --report <结果文件路径>
```

验收使用随机端口、临时数据目录和独立密钥，不修改正在运行的实例。覆盖默认值、管理员权限、首次改密限制、多主体读取、SSE、目录模式、公开访问、文档与附件、搜索、ZIP 快照恢复、旧接口不可调用以及重启后的持久化。

前端执行 `npm test`、`npm run lint` 和 `npm run build`。后端执行 `go test ./...` 与 `go vet ./...`。旧数据库结构清理另有保留账户内容的回归测试。

## 后台部署

正式部署应将前端嵌入服务端程序，使用稳定数据目录和持久密钥。HTTPS 入口需要正确的证书及反向代理头，SSE 路径不能启用代理缓冲。使用容器后台运行时，为应用与 HTTPS 网关配置 `unless-stopped` 自动恢复策略。局域网其他设备必须信任签发服务证书的 CA，不能通过关闭证书验证代替安装证书。

部署端口、局域网地址和数据位置由部署环境实际检测，不将本机地址写入程序默认值。验收异常恢复后，保持正式容器运行。
